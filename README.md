# Bootstrap 5 Co-working Space UI

A fully responsive, single-page landing page for a modern co-working space. This project was built strictly using HTML5 and Bootstrap 5 to demonstrate a strong understanding of core Bootstrap components, layout systems, and utility classes without relying on custom CSS.

## 🚀 Key Features

- **List Groups:** Clean, structured presentation of upcoming events utilizing Bootstrap's List Group component.
- **Responsive Grid Layout:** Seamless adaptation across mobile, tablet, and desktop screens using Bootstrap's 12-column grid system (`col-12`, `col-md-6`, `col-lg-4`).
- **Dynamic Flexbox Alignment:** Extensive use of `d-flex` and `justify-content` utilities for precise responsive positioning in the header, footer, and individual cards.
- **Visual Indicators:** Implementation of **Progress Bars** for capacity tracking, and **Badges** for room availability status.
- **Responsive Tables:** A detailed membership pricing table wrapped in `table-responsive` to ensure perfect mobile viewing without breaking the layout.
- **Interactive Elements:** Integration of Button Groups, Alerts, Breadcrumbs, and Pagination components for a complete and realistic user interface.

## 🛠 Built With

* [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) - Semantic structure
* [Bootstrap 5.3](https://getbootstrap.com/) - Frontend CSS framework
* [Bootstrap Icons](https://icons.getbootstrap.com/) & FontAwesome - Modern UI iconography

## ⚙️ Quick Start

Simply clone the repository and open `index.html` in any web browser. No build tools or package managers are required, as Bootstrap and Icon libraries are directly imported via CDN.
